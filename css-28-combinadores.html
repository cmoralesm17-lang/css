Leccion CSS 28 - Combinators

1. Descendant combinator (espacio) - div p

Este p es hijo directo del div - SI se pinta amarillo.

Este p esta dentro de otro div (nieto) - TAMBIEN se pinta amarillo.

Este p esta FUERA del div - no se pinta.

El combinador de espacio selecciona TODOS los descendientes, sin importar cuantos niveles de profundidad.

2. Child combinator (>) - div > p

Este p es hijo DIRECTO del div - SI se pinta amarillo.

Este p es nieto (hijo de un div interno, no del div principal) - NO se pinta.

Solo selecciona hijos directos (un nivel), no nietos ni descendientes mas profundos.

3. Next sibling combinator (+) - div + p

Un div cualquiera

Este es el PRIMER p justo despues del div - SI se pinta amarillo.

Este es el SEGUNDO p (hermano, pero no el inmediato despues del div) - NO se pinta.

Solo selecciona el elemento que esta INMEDIATAMENTE despues, y solo uno.

4. Subsequent-sibling combinator (~) - div ~ p

Un div cualquiera

Este p (el primero despues del div) - SI se pinta amarillo.

Este p (el segundo despues del div) - TAMBIEN se pinta amarillo.

Este p (el tercero) - TAMBIEN se pinta amarillo.

Selecciona TODOS los hermanos que vienen despues, no solo el inmediato.

Resumen comparativo

Combinador Simbolo Que selecciona
DescendantespacioTodos los descendientes (hijos, nietos, etc.)
Child>Solo hijos directos (un nivel)
Next sibling+Solo el hermano inmediatamente siguiente
Subsequent-sibling~Todos los hermanos que vienen despues
