Leccion CSS 22 - Position

1. position: static (por defecto)

Este div tiene position:static. Sigue el flujo normal de la pagina, top/left/right/bottom no le afectan.

2. position: relative

Este div tiene position:relative y left:30px, asi que se desplaza 30px a la derecha de donde estaria normalmente. El espacio original que ocupaba SI se mantiene reservado.

3. position: fixed

Este es contenido normal de la pagina. Mira la esquina inferior derecha de la PANTALLA (no de este recuadro) - ahi hay un elemento fixed que se queda ahi sin importar cuanto hagas scroll.
Este div tiene position:fixed, siempre visible en la esquina inferior derecha de la ventana.

4. position: absolute (relativo al padre con position)

Este div padre tiene position:relative.
Este div hijo tiene position:absolute, se posiciona respecto al padre relativo (no respecto a toda la pagina).

Un elemento absolute se saca del flujo normal y puede superponerse con otros elementos.
