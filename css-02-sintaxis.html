Este parrafo esta centrado y en color rojo, gracias a la regla CSS aplicada a todos los elementos p de esta pagina.

Este segundo parrafo tambien recibe el mismo estilo, porque el selector "p" afecta a TODOS los parrafos.

Partes de una regla CSS (explicacion)

Una regla CSS tiene un selector y un bloque de declaracion:

  • Selector: apunta al elemento HTML que se quiere estilizar (en el ejemplo de arriba, es "p").
  • Bloque de declaracion: va entre llaves { }, y contiene una o mas declaraciones separadas por punto y coma.
  • Declaracion: tiene una propiedad y un valor, separados por dos puntos (ej. color: red;).

Desglose del ejemplo

p es el selector (apunta al elemento <p>).
color es una propiedad, y red es su valor.
text-align es una propiedad, y center es su valor.
