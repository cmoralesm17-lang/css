Leccion CSS 12 - Box Model

Las 4 partes del modelo de caja (de adentro hacia afuera)

  • Content - el contenido en si (texto, imagenes)
  • Padding - espacio alrededor del contenido, transparente
  • Border - borde que rodea al padding y al contenido
  • Margin - espacio fuera del borde, transparente

1. Demostracion visual del box model

Este div tiene width:300px, border:15px solid green, padding:50px, margin:20px. Puedes ver claramente las 4 capas: el fondo amarillo es el contenido+padding, el borde verde grueso es el border, y el espacio blanco alrededor es el margin.

2. Calculo del ancho y alto TOTAL de un elemento

width:320px, height:50px, padding:10px, border:5px solid gray, margin:0

Calculo del ancho total:

  320px (ancho del area de contenido)
+  20px (padding izquierdo 10px + padding derecho 10px)
+  10px (borde izquierdo 5px + borde derecho 5px)
= 350px (ancho TOTAL)

Calculo del alto total:

   50px (alto del area de contenido)
+  20px (padding arriba 10px + padding abajo 10px)
+  10px (borde arriba 5px + borde abajo 5px)
=  80px (alto TOTAL)

Formulas generales

Ancho total = width + padding izquierdo + padding derecho + borde izquierdo + borde derecho

Alto total = height + padding arriba + padding abajo + borde arriba + borde abajo

Nota importante sobre el margin

El margin SI afecta el espacio total que ocupa la caja en la pagina (empuja a los demas elementos), pero NO se cuenta dentro del tamaño real de la caja. El tamaño de la caja (ancho/alto) termina justo en el borde, el margin es "espacio adicional" fuera de esa caja.

Esta leccion conecta directamente con box-sizing: border-box que vimos en Padding — esa propiedad justamente cambia esta formula, haciendo que width/height incluyan padding y borde automaticamente, en vez de tener que sumarlos aparte.
