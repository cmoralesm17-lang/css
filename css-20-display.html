4. Los 6 valores mas comunes de display

display: inline (no rompe linea)

display: block (ocupa todo el ancho)

display: inline-block (no rompe linea, pero acepta width/height/padding)

display: flex (contenedor flexible)

display: grid (contenedor de cuadricula)

7. display:none vs visibility:hidden

Este titulo esta oculto con display:none

El titulo de arriba (display:none) NO ocupa espacio, es como si no existiera en la pagina.

Este titulo esta oculto con visibility:hidden

El titulo de arriba (visibility:hidden) SI ocupa su espacio en blanco, aunque no se vea el texto (nota el espacio vacio antes de este parrafo).
