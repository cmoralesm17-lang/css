Leccion CSS 11 - Height and Width

1. Altura y ancho basico

Este elemento tiene height: 70px y width: 100%.

2. Altura fija, ancho en porcentaje

Este elemento tiene height: 200px y width: 50%.

3. Altura y ancho fijos en pixeles

Este elemento tiene height: 100px y width: 500px.

4. Height/width NO incluyen padding ni borde (importante)

Este div tiene height:100px y width:200px definidos, MAS padding:20px y border:5px. El tamaño visual final es mayor a 100x200, porque el padding y el borde se agregan por fuera del area de contenido.

Valores posibles para height y width

  • auto - valor por defecto, el navegador calcula el tamaño
  • length - un valor fijo en px, cm, em, etc.
  • % - un porcentaje del tamaño del contenedor padre
  • initial - vuelve al valor por defecto
  • inherit - hereda el valor del elemento padre

5. width vs max-width (achica la ventana del navegador para ver la diferencia)

Este div tiene width:600px fijo. Si la ventana del navegador es mas angosta que 600px, apareceria una barra de scroll horizontal.

Este div tiene max-width:600px. Si la ventana es mas angosta, este div se encoge para adaptarse, sin generar scroll horizontal.

6. Comparacion directa: max-width vs width

Este div1 tiene max-width: 500px
Este div2 tiene width: 500px

7. Cuando width Y max-width estan juntos, gana max-width si width es mayor

Este div tiene width:100% (podria ser muy ancho en pantallas grandes) PERO max-width:900px, asi que nunca crecera mas alla de 900px, sin importar que tan ancha sea la pantalla.

8. min-height (bonus: la misma logica aplica a min-width y max-height)

Este div tiene min-height:150px. Aunque el contenido sea poco, nunca sera mas bajo que 150px. Si el contenido crece mas alla de eso, el div crece con el contenido normalmente.
