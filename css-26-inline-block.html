Leccion CSS 26 - Inline-block

1. Comparacion: inline vs inline-block vs block

display: inline (el default de span)

1 2 3

Se quedan en la misma linea, PERO no aceptan width/height (el border/padding se ve, pero no puedes forzar un tamaño exacto).

display: inline-block

1 2 3

Se quedan en la misma linea Y SI aceptan width/height/margin-top/margin-bottom, como si fueran block pero sin romper la linea.

display: block

1 2 3

Cada uno rompe la linea y ocupa su propio espacio, uno debajo del otro.
