Leccion CSS 27 - Align

1. Centrado completo (horizontal y vertical) con Flexbox

Estoy centrado horizontal y verticalmente

El metodo mas moderno y recomendado: display:flex + justify-content:center + align-items:center.

2. Alineacion horizontal

margin: auto (centrar elementos de bloque)

Este div esta centrado, con width:50% definido (sin width, margin:auto no hace nada).

text-align: center (centrar texto dentro de un elemento)

Este texto esta centrado.

Centrar una imagen

La imagen es inline por defecto, por eso se le pone display:block antes de aplicar margin-left/right:auto.

Alinear con position: absolute

Este div esta posicionado a la derecha con position:absolute.

Alinear con float

Este div esta alineado a la derecha con float:right.

3. Alineacion vertical

Centrado vertical con Flexbox

Estoy centrado vertical y horizontalmente con flex.

Centrado vertical con Grid

Estoy centrado con display:grid y place-items:center.

Centrado con position + transform (para elementos de tamaño desconocido)

Estoy centrado con position:absolute + transform:translate(-50%, -50%).
