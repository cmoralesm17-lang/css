Como agregar CSS

Hay tres formas de insertar CSS en una pagina: externo, interno, y en linea.

1. CSS Externo (ejemplo de referencia)

Se conecta un archivo .css aparte usando <link> en el head:

<link rel="stylesheet" href="mystyle.css">

Y el archivo "mystyle.css" (sin ninguna etiqueta HTML adentro, solo CSS puro) se veria asi:

body {
  background-color: lightblue;
}
h1 {
  color: navy;
  margin-left: 20px;
}

Ventaja: puedo cambiar el diseño de muchas paginas HTML a la vez, editando un solo archivo .css.

2. CSS Interno

El CSS interno se define dentro de una etiqueta <style> en el head. En este mismo archivo, el bloque <style> define que los <h1> sean color naranja (mira el titulo de arriba de todo).

3. CSS en linea (Inline)

Este parrafo tiene su color aplicado directo en el atributo style="color:red;".

El CSS en linea se recomienda usar poco, porque mezcla contenido con presentacion.

Multiples hojas de estilo y orden de cascada

Si un archivo externo dijera "h1 { color: navy; }" y el interno (como el de este archivo) dijera "h1 { color: orange; }", gana el que se lea DE ULTIMO en el head:

  • Si el <link> externo va primero y el <style> interno despues → gana el interno (orange)
  • Si el <style> interno va primero y el <link> externo despues → gana el externo (navy)

Orden de prioridad en cascada (de mayor a menor):

  1. Estilo en linea (dentro del elemento HTML) — la mayor prioridad
  2. Hojas de estilo externas e internas (en el head) — prioridad media, gana la que se lea de ultimo
  3. Estilos por defecto del navegador — la menor prioridad

Por eso, el parrafo de CSS en linea de arriba (rojo) siempre ganaria sobre cualquier regla externa o interna que tambien intentara ponerle color a los parrafos, sin importar el orden en que esten escritas.
