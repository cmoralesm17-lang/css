Selectores de CSS

1. Selector de elemento

Este selector afecta a TODOS los elementos p de la pagina (aqui alineados a la izquierda).

2. Selector de id (unico)

Este parrafo tiene id="para1", por eso esta centrado y en rojo. Solo puede haber UN elemento con este id en toda la pagina.

3. Selector de clase (general)

Este parrafo tiene class="center", por eso esta centrado y en azul.

Este h3 tambien tiene class="center", y recibe el mismo estilo aunque sea otro tipo de elemento.

4. Selector de clase combinado con elemento (p.center)

Este parrafo con class="center" ahora se ve verde y en negrita, porque coincide con la regla mas especifica "p.center" (que sobreescribe a la regla ".center" generica).

5. Elemento con multiples clases

Este parrafo tiene DOS clases al mismo tiempo: "center" y "large". Recibe los estilos de ambas: texto centrado, verde, negrita (de p.center) y tamaño grande (de .large).

6. Selector universal (*)

Todo el texto dentro de este div es morado, sin importar la etiqueta (p, b, span), porque el selector universal * afecta a todo.

Este parrafo tambien es morado.

7. Selector de agrupacion (coma)

Este h4 esta centrado y naranja

Este h5 tambien esta centrado y naranja

Este parrafo con class="agrupado" tambien recibe el mismo estilo, porque agrupe "h4, h5, .agrupado" en una sola regla con comas, en vez de escribir 3 reglas separadas.

8. Tabla resumen de selectores simples

Selector Ejemplo Descripcion
#id #para1 Selecciona el elemento con id="para1"
.class .center Selecciona todos los elementos con class="center"
* * Selecciona todos los elementos
elemento p Selecciona todos los elementos p
elemento,elemento h4, h5 Selecciona todos los h4 y todos los h5
