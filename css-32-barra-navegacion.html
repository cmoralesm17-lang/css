11. Navbar fijo (referencia, no aplicado a toda la pagina)

Para que un navbar se quede fijo arriba o abajo de TODA la pagina (no solo un contenedor), se usa:

ul {
  position: fixed;
  top: 0;    /* o bottom: 0; para fijarlo abajo */
  width: 100%;
}

No lo active en toda la pagina para no tapar el resto del contenido de este archivo de practica, pero la sintaxis es identica a position:sticky que ya usamos, solo que fixed nunca se comporta como relative.
