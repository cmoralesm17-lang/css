9. HEX de 3 digitos (forma corta)

background-color: #fc9; (equivale a #ffcc99)

color: #f0f; (equivale a #ff00ff)

color: #b58; (equivale a #bb5588)

Solo funciona si los 2 digitos de cada color (RR, GG, BB) son iguales entre si.
