Leccion CSS 21 - Max-width

El problema con width fijo

Este div tiene width:500px fijo, y margin:auto para centrarlo.

Si la ventana del navegador se hace mas angosta que 500px, este div NO se encoge: parte del contenido se corta o aparece una barra de scroll horizontal en toda la pagina.

La solucion con max-width

Este div tiene max-width:500px en vez de width, y margin:auto para centrarlo.

Este div se sigue viendo igual mientras haya espacio suficiente, PERO si la ventana se hace mas angosta que 500px, el div se encoge junto con ella, sin cortar contenido ni generar scroll horizontal.

Como probarlo

Reduce el ancho de la ventana de tu navegador (o achica la ventana) a menos de 500px, y compara el comportamiento de ambos divs: el primero se queda rigido, el segundo se adapta.

Por que es importante

max-width es clave para el diseño responsive: permite que un elemento tenga un tamaño maximo "ideal" en pantallas grandes, pero se adapte automaticamente a pantallas pequeñas (celulares, tablets), sin necesidad de escribir media queries adicionales solo para este caso.
