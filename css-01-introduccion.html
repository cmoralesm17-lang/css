Que es CSS?

CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada).

CSS describe como se deben mostrar los elementos HTML en pantalla, papel, o en otros medios.

CSS ahorra mucho trabajo: puede controlar el diseño de multiples paginas web al mismo tiempo, ya que se puede definir una sola vez y reutilizar en todo un sitio.

Para que se usa CSS

CSS se usa para definir el diseño, la distribucion (layout), y las variaciones de presentacion para distintos dispositivos y tamaños de pantalla.
