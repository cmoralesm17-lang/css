Leccion CSS 16 - Icons

Como funcionan los iconos en la web

Los iconos se agregan usando una libreria de iconos: se conecta un archivo externo (con <link> o <script>) en el head, y luego cada icono es simplemente una etiqueta <i> o <span> con una clase especial. Son vectores escalables, por lo que se pueden personalizar con CSS igual que cualquier texto (tamaño, color, sombra).

1. Font Awesome (referencia - requiere cuenta propia)

Para usar Font Awesome hay que crear una cuenta gratuita en fontawesome.com y obtener un codigo personal (kit) para pegar en el head, algo asi:

<script src="https://kit.fontawesome.com/tu-codigo.js" crossorigin="anonymous"></script>

Y luego los iconos se usan asi:

<i class="fas fa-cloud"></i>
<i class="fas fa-heart"></i>
<i class="fas fa-car"></i>

No lo active en este archivo porque necesita un codigo de cuenta personal que no tengo, pero la logica es identica a los iconos de Google que si funcionan abajo.

2. Google Icons (Material Icons) - funcionando

Estos si funcionan directamente, sin necesidad de cuenta, con solo este link en el head:

<link rel="stylesheet" href="https://fonts.googleapis.com/icon?family=Material+Icons">
cloud favorite attachment computer traffic

3. Personalizando iconos con CSS

Como son texto/vectores, se pueden estilizar igual que cualquier otro elemento:

Color

Sombra
